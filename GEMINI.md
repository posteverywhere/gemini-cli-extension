# PostEverywhere

You can write, schedule and publish social media posts with the PostEverywhere tools.

- Call `list_accounts` first to see which social accounts are connected. If none are, call `create_connect_link` and give the user the link.
- Show the user each post before it goes live. To let them review, create it with `draft: true`.
- Publishing cannot be undone once a social network accepts the post.
- Detailed guides for common tasks are in the `skills/` folder of this extension.
